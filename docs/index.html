Up and running
in a minute.

Lượm is verified by Apple, so it opens like any other app.

Open the download

Double-click the file and drag Lượm into Applications.

Open Lượm

If macOS asks whether to open an app from the internet, click Open.

Allow reminders

Let Lượm send notifications, so pop quizzes and reminders reach you.

Turn on the shortcut

Allow Lượm under Accessibility so ⌥⌘E can read your selection.

Needs a Mac with Apple Silicon (M1 or newer) and macOS 12 or later.
